# Tests

## Test 1 - Add a verb, correct one conjugated form, and see it on the flashcard [sanity]
Viewport: desktop
Covers: fixed category navigation, verb creation triggering automatic conjugation generation, flashcard register/tense/negation switcher, manual correction of a single generated form, persistence after reload, AI example sentence on the flashcard back
Description: Verifies that opening one of the app's built-in categories, adding a verb, auto-generates its conjugations and an example sentence, that switching register/tense/negation on the flashcard changes what is displayed, and that a manually corrected form is saved and shown both in word management and on the flashcard.

Steps:
1. On the main menu, open the "Verbes" category card
2. Go to "Gérer les mots" then "Ajouter un mot": Korean word "가다", pronunciation "gada", translation "aller", then submit and wait for the add to finish
3. Go to the "Verbes" flashcard view and note the Korean word shown on the front of the card
4. Use the "Temps" switcher below the card to select "Présent"
5. Click the card to flip it
6. Go back to "Gérer les mots", click the row for "가다" to expand its conjugations, then select register "Familier", temps "Présent" and négation "Affirmatif" in the switcher
7. Click the pencil icon next to the displayed form, enter "테스트폼" as the Korean word and "tesuteupom" as pronunciation, then save
8. Refresh the page, re-expand the conjugations for "가다", and reselect register "Familier", temps "Présent", négation "Affirmatif"
9. Go to the "Verbes" flashcard view and set its switcher to register "Familier", temps "Présent", négation "Affirmatif"

Expected: In step 4, switching to "Présent" changes the Korean word shown on the card to something different from what was shown in step 3. In step 5, flipping the card reveals the French translation "aller" plus a short Korean example sentence with its own translation underneath. After step 7 the correction is saved. After the refresh in step 8, the "Familier" / "Présent" / "Affirmatif" conjugation still shows "테스트폼" / "tesuteupom". In step 9, the flashcard front also shows "테스트폼" for that same combination.

## Test 2 - Reset all data from Settings
Viewport: desktop
Covers: destructive-action confirmation, global data wipe across all categories, persistence after reload

Setup:
1. Open "Adjectifs", go to "Gérer les mots" then "Ajouter un mot", and add the word "크다" / "keuda" / "être grand"

Description: Verifies that the Settings panel's "Tout effacer" action requires confirmation and permanently wipes every word in every category.

Steps:
1. From the main menu, click the settings (gear) icon in the header
2. Click "Tout effacer"
3. Confirm the destructive action in the confirmation dialog
4. Refresh the page

Expected: The "Adjectifs" category card shows 0 mots immediately after the reset, and opening "Adjectifs" shows an empty word list, both before and after the refresh.

## Test 4 - Warn about a duplicate word on manual add
Viewport: desktop
Covers: fixed category navigation, duplicate detection guardrail, term index lookup, force-add override

Setup:
1. Open "Particules", go to "Gérer les mots" then "Ajouter un mot", and add the word "은/는" / "eun/neun" / "particule de thème"

Description: Verifies that adding a word that already exists elsewhere surfaces a duplicate warning instead of silently creating a second copy.

Steps:
1. From the "Particules" word list, click "Ajouter un mot"
2. Enter the same term "은/는" again (any pronunciation/translation) and submit
3. Dismiss the duplicate warning without confirming

Expected: A duplicate warning appears mentioning the "Particules" category, and after dismissing it the "Particules" word list still shows exactly one "은/는" entry.

## Test 5 - Photo import shows a visible error when extraction fails
Viewport: desktop
Covers: photo import trigger, AI extraction request, user-visible error handling for a failed extraction

Description: Verifies a failed AI photo-extraction request surfaces as a visible error instead of silently doing nothing.

QA Faults:
```json
[
  {
    "method": "POST",
    "path": "/api/extract-words",
    "status": 500,
    "body_json": { "error": "simulated_failure" }
  }
]
```

Steps:
1. From the main menu, click "Ajouter des mots par photo"
2. Choose/upload any image file

Expected: A visible error message indicates the photo analysis failed, a retry option is shown, and no candidate word list appears.
