# Tests

## Test 1 - Add a verb, correct one conjugated form, and see it on the flashcard [sanity]
Viewport: desktop
Covers: category creation, verb creation triggering automatic conjugation generation, flashcard register/tense/negation switcher, manual correction of a single generated form, persistence after reload
Description: Verifies that adding a verb auto-generates its conjugations, that switching register/tense/negation on the flashcard changes what is displayed, and that a manually corrected form is saved and shown both in word management and on the flashcard.

Steps:
1. On the main menu, click "Nouvelle catégorie", type "Verbes" and confirm creation
2. Open "Verbes", go to "Gérer les mots" then "Ajouter un mot": Korean word "가다", pronunciation "gada", translation "aller", then submit and wait for the add to finish
3. Go to the "Verbes" flashcard view and note the Korean word shown on the front of the card
4. Use the "Temps" switcher below the card to select "Présent"
5. Go back to "Gérer les mots", click the row for "가다" to expand its conjugations, then select register "Familier", temps "Présent" and négation "Affirmatif" in the switcher
6. Click the pencil icon next to the displayed form, enter "테스트폼" as the Korean word and "tesuteupom" as pronunciation, then save
7. Refresh the page, re-expand the conjugations for "가다", and reselect register "Familier", temps "Présent", négation "Affirmatif"
8. Go to the "Verbes" flashcard view and set its switcher to register "Familier", temps "Présent", négation "Affirmatif"

Expected: In step 4, switching to "Présent" changes the Korean word shown on the card to something different from what was shown in step 3. After step 6 the correction is saved. After the refresh in step 7, the "Familier" / "Présent" / "Affirmatif" conjugation still shows "테스트폼" / "tesuteupom". In step 8, the flashcard front also shows "테스트폼" for that same combination.

## Test 4 - Warn about a duplicate word on manual add
Viewport: desktop
Covers: duplicate detection guardrail, term index lookup, force-add override

Setup:
1. Create a category named "Particules"
2. Open "Particules", go to "Gérer les mots" then "Ajouter un mot", and add the word "은/는" / "eun/neun" / "particule de thème"

Description: Verifies that adding a word that already exists elsewhere surfaces a duplicate warning instead of silently creating a second copy.

Steps:
1. From the "Particules" word list, click "Ajouter un mot"
2. Enter the same term "은/는" again (any pronunciation/translation) and submit
3. Dismiss the duplicate warning without confirming

Expected: A duplicate warning appears mentioning the "Particules" category, and after dismissing it the "Particules" word list still shows exactly one "은/는" entry.

## Test 5 - Photo import shows a visible error when extraction fails
Viewport: desktop
Covers: photo import trigger, AI extraction request, user-visible error handling for a failed extraction

Description: Verifies a failed AI photo-extraction request surfaces as a visible error instead of silently doing nothing.

QA Faults:
```json
[
  {
    "method": "POST",
    "path": "/api/extract-words",
    "status": 500,
    "body_json": { "error": "simulated_failure" }
  }
]
```

Steps:
1. From the main menu, click "Ajouter des mots par photo"
2. Choose/upload any image file

Expected: A visible error message indicates the photo analysis failed, a retry option is shown, and no candidate word list appears.
