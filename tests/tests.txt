# Tests

## Test 1 - Create a verb with register/conjugation, review it, and edit it [sanity]
Viewport: desktop
Covers: category creation, manual word creation with register/conjugation selection, database create, flashcard flip/reveal showing register+conjugation badges, word edit, persistence after reload
Description: Verifies the core verb workflow — creating a "Verbes" category, adding a verb with a non-default register/conjugation, reviewing it as a flashcard with the right badges, editing it, and confirming the change persists.

Steps:
1. On the main menu, click "Nouvelle catégorie", type "Verbes" and confirm creation
2. Open "Verbes", go to "Gérer les mots" then "Ajouter un mot"
3. Fill in "가다" as the Korean word, "gada" as pronunciation, "aller" as translation, select register "Familier" and conjugation "Présent", then submit
4. Go to the "Verbes" flashcard view and click the card to flip it
5. Go back to "Gérer les mots", click the edit icon on "가다", change the register to "Poli", and save
6. Refresh the page and open "Verbes" again

Expected: After step 4, the front of the card shows "가다" / "gada" with badges "Familier" and "Présent", and flipping reveals "aller". After the edit and refresh, the word list for "Verbes" shows "가다" with badges "Poli" and "Présent" (register changed, conjugation unchanged).

## Test 4 - Warn about a duplicate word on manual add
Viewport: desktop
Covers: duplicate detection guardrail, term index lookup, force-add override

Setup:
1. Create a category named "Particules"
2. Open "Particules", go to "Gérer les mots" then "Ajouter un mot", and add the word "은/는" / "eun/neun" / "particule de thème"

Description: Verifies that adding a word that already exists elsewhere surfaces a duplicate warning instead of silently creating a second copy.

Steps:
1. From the "Particules" word list, click "Ajouter un mot"
2. Enter the same term "은/는" again (any pronunciation/translation) and submit
3. Dismiss the duplicate warning without confirming

Expected: A duplicate warning appears mentioning the "Particules" category, and after dismissing it the "Particules" word list still shows exactly one "은/는" entry.
